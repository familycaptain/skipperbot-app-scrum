# skipperbot-app-scrum

A Skipperbot **app package** — a daily-standup / scrum tracker for a household
that runs like a software-dev team. Every morning the platform's daily PM update
hands each person a short check-in (what you finished, what you're focused on,
what's blocking you), this app files those items, and you answer them in chat or
in the Scrum app — answering can roll the underlying task forward.

> **Niche by design.** This is a tracker for families who run their home like a
> dev shop with goals, projects, and tasks. Most households won't want it — it's
> shipped as a separate installable package precisely so it isn't forced on
> everyone.

## What it is

- A `scrum_items` table (in this app's own `app_scrum` schema), one row per
  person per daily check-in item.
- Two chat tools — `get_pending_scrum_items` and `respond_to_scrum_item` — so the
  LLM can read your open items and record your replies (optionally marking a
  linked task done / in progress / blocked).
- A small desktop app that groups items by day and lets you reply inline.

## Who it's for

Households that already drive their day off the **Goals** app (goals → projects →
tasks) and want a lightweight morning standup to stay on top of it. If you don't
run your home that way, you don't need this app.

## Install

```bash
# from a running skipperbot-platform checkout:
cd apps
git clone <this-repo> scrum
cd .. && # restart the platform — the loader discovers apps/scrum/ on boot
```

The clone target directory **must** be `scrum` (the app id) so it lands at
`skipperbot-platform/apps/scrum`. On boot the loader runs
`migrations/001_initial.sql` (creating the `app_scrum` schema + `scrum_items`),
registers the routes at `/api/apps/scrum`, the chat tools, and the desktop app.

This app depends on the **Goals** app to generate the daily items. Goals is a
core/always-present platform app, so that dependency is already satisfied on any
standard install — there is nothing extra to install for it.

## How it works

1. Each morning the platform's **Goals/PM daily-update runner** scans your goals,
   projects, tasks, and schedules and produces a personalized check-in per
   person. When this app is installed, the runner persists those items into
   `app_scrum.scrum_items` (via `save_scrum_items_bulk`). **The items are
   generated by the platform's PM runner, not by this app — this app stores and
   surfaces them.**
2. You respond, two ways:
   - **In chat** — reply to your PM check-in; the LLM matches your reply to your
     open items, calls `respond_to_scrum_item` for each, and (where the item is
     linked to a task) marks that task done / in progress / blocked.
   - **In the Scrum app** — click **Reply** on any of today's items; the response
     is saved and also pushed through the chat pipeline so the LLM can act on it.

## Layout

```
manifest.yaml          app manifest (id: scrum, entity type, tool category, ui)
__init__.py            package marker
data.py                data layer (app_scrum schema)
tools.py               chat tools (get_pending / respond)
routes.py              REST router, mounted at /api/apps/scrum
migrations/            per-app SQL migrations (001_initial.sql)
ui/index.js            launcher registration
ui/ScrumApp.jsx        desktop UI (auto-discovered by the platform's Vite glob)
guide.md               agent guide
help.md                user manual
specs/SPEC.md          spec
```
